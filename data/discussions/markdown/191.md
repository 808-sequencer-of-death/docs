Does CR26 prohibit processing/transmitting/storing data in non-US locations?  If not, what should happen when doing a Rev5 Ready Conversion and the system has a non-US region in boundary?

## pete-gov (FedRAMP) — [2026-11-05T21:50:06Z](https://github.com/FedRAMP/community/discussions/191#discussioncomment-19427565)

> Does CR26 prohibit processing/transmitting/storing data in non-US locations? If not, what should happen when doing a Rev5 Ready Conversion and the system has a non-US region in boundary?

For Rev5, this is an [Organization-Defined Parameter in SA-09(05)](https://www.fedramp.gov/2026/reference/controls/system-and-services-acquisition/#sa-09-05). The restriction to U.S. locations is only for Class D. This ODP did not change in CR26, it's the same as it has been historically. This only ever applied to Class D/High for agency authorizations.

For the other classes, you would be expected to document the locations in that control as normal.
