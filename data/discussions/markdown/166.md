# Issues with FedRAMP Schema Validator
Source: https://github.com/FedRAMP/community/discussions/166

## Original post — gmengelberg, 2026-08-28T18:22:54Z

There may be an issue w/ the [FedRAMP Schema Validator](https://www.fedramp.gov/schemas/validator/?schema=fedramp-security-decision-record-schema-2026-06-24.json) processing valid SDRs. The validator returns `no schema with key or ref "https://json-schema.org/draft/2020-12/schema"` which suggests the validator is unable to resolve the draft 2020-12 meta-schema.

Local testing by multiple parties using valid SDRs pass successfully.
