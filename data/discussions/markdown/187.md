# A free, agency-neutral implementation workbook built in the spirit of FedRAMP 20x
Source: https://github.com/FedRAMP/community/discussions/187

## Original post — WhalerMike, 2026-10-31T21:26:26Z

FedRAMP 20x, along with the Federal CIO’s “Expectations for Public Tech Leadership” memo, inspired a project I’ve been building: the Federal Modernization Workbook, https://whalermike.github.io/modernization-workbook/

It’s a free, open set of books for civilian agencies on moving from AD-mastered identity to HR-driven, cloud-governed operations under CISA baselines (SCuBA, BODs, 800-53 Moderate). The gap it tries to fill is the same one 20x names: requirements arrive without a shared way to implement them, so each agency works it out alone. The workbook tries to show its work, with every claim sourced and corrections logged in the open.

It isn’t a cloud service offering and isn’t seeking authorization. I’m sharing it as a community resource and would welcome feedback from the FedRAMP team and community on two questions:

Where does the workbook’s treatment of continuous, evidence-based compliance line up with 20x, and where does it diverge?
What would make it more useful to agencies consuming 20x-authorized services?
Start here: https://whalermike.github.io/modernization-workbook/docs/start-here.html#the-start-series
