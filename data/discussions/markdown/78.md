Last week the FedRAMP 20x Phase One pilot stopped accepting public submissions and you have questions:

- What does that mean for the future of 20x? 
- When will the Phase One pilot end? 
- When will the Phase Two pilot start? 
- When will agencies start adopting 20x?
- What is the new [Authorization Data Sharing (ADS) Standard](https://www.fedramp.gov/20x/standards) that was just quietly released for 20x?

### We'll be sharing updates on these questions and more this Wednesday 8/27 from 1pm to 2pm Eastern in our regular 20x Community Working Group meeting.

If for some reason you aren't already signed up, [do it here now](https://gsa.zoomgov.com/meeting/register/FpW3sJuBRxag_1Mz49J0Cw).

### But wait, there's more!

FedRAMP's really focused on showing instead of just telling wherever possible, and this week we're all going to see something special together!

[Google Cloud Compliance Manager](https://cloud.google.com/blog/products/identity-security/streamline-auditing-compliance-manager-is-now-in-preview/?e=48754805) is a new solution that integrates with Security Command Center (SCC) and provides a unified platform for configuring, monitoring, and auditing security and compliance. [As announced in a recent blog](https://cloud.google.com/blog/topics/public-sector/accelerating-fedramp-20x-how-google-cloud-is-automating-compliance?e=48754805), Compliance Manager **will natively support FedRAMP 20x compliance.**

Some awesome folks from Google will be showcasing the capability of this product built to natively support FedRAMP 20x on Google Cloud Platform:

- **Ruchi Khurana** - Lead Product Manager, Cloud Security and Compliance
- **Will Shah** - Technical Program Manager, Cloud CISO
- **Ben Fowler** - Technical Program Manager, Cloud CISO

This is going to be a particularly special meeting, but as always if you miss it live you'll be able to catch it on [our YouTube channel soon after the event](https://youtube.com/fedramp).
