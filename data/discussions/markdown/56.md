# Mark43 | FedRAMP 20x Phase One Pilot Submission
Source: https://github.com/FedRAMP/community/discussions/56

## Original post — kelseymcmichael, 2025-07-02T17:26:55Z

This discussion provides an overview of Mark43's participation in the FedRAMP 20x Phase One pilot. We are submitting two separate environments for this pilot to demonstrate our cloud service’s readiness for FedRAMP authorization using an automated, machine-readable approach. This submission aligns with the FedRAMP 20x initiative, which aims to streamline validation through Key Security Indicators (KSIs), reusable evidence, and automation.

**Key Information:**
_FedRAMP High Environment:_ A fully FedRAMP High authorized environment deployed in AWS GovCloud. Compliance documentation and evidence are stored in an S3 bucket for easy access.
[View Repo](https://github.com/mark43/Mark43-High-FedRAMP20x-Phase1)

_SLG-Focused Environment:_ A non-FedRAMP authorized environment aligned with FedRAMP Low/SOC 2 controls, undergoing validation under the 20x initiative.
[View Repo](https://github.com/mark43/Mark43-FedRAMP20x-Phase1)

**Important Note:**
The data provided in these repositories is placeholder content intended to illustrate the structure of our final submission. This reflects how Mark43 plans to submit the complete package, which will be iteratively refined through an agile process in collaboration with our 3PAO and the FedRAMP PMO. Feedback from these parties will be used to validate and enhance the submission.

As part of the agile methodology under FedRAMP 20x, we will progressively integrate KSI validation assertions, evidence collection, and other supporting documentation as we receive feedback and make the necessary updates.
