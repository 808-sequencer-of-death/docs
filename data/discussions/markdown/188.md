## pete-gov (FedRAMP) — [2026-11-04T13:19:05Z](https://github.com/FedRAMP/community/discussions/188#discussioncomment-19397947)

> I am attempting to submit an FRC-CSP-PKG Rev5 but, I'm receive an error message stating, "JSON Schema URL (CR26: FRC-CSO-PKG): is invalid". 

Most likely this is because of either a missing [Cross-Origin Resource Sharing or Content-Type header](https://www.fedramp.gov/2026/reference/fedramp-certification/#fedramp-json-schemas) on the JSON being served from your web server. Our app that processes these submission requests and imports this data needs standard webapp headers to process this data. We recommend working with a web app engineer to get this set up right.

If you google "CORS Tester" or similar you can find plenty of online tools to help debug CORS and web server headers.

If you're still having problems after testing that, go ahead and ship an email to info@fedramp.gov with the specific URL so we can help debug it for you, but most likely it's the headers.
