## This thread is for any and all Q&A or general discussion related to FedRAMP 20x in general that does not need to have its own thread.

FedRAMP released the [Consolidated Rules for 2026](https://www.fedramp.gov/2026/) on June 24, 2026 with all requirements for FedRAMP 20x Class A, B, and C.

This includes:

- When each certification is available for application
- All the rules and expectations for a FedRAMP 20x Certification
- Basic JSON schemas for providing some high level machine-readable data
- So much more

We're excited for folks to continue digging in after the Public Preview and begin preparing. We're happy to answer any general questions that don't need their own thread here!
