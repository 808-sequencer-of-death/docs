# Complete List of Class A Requirements
Source: https://github.com/FedRAMP/community/discussions/190

## Original post — not-too-sweet, 2026-11-04T22:25:48Z

Has anyone found one reliable way to list everything that's a MUST and SHOULD for Class A including the rules pulled in by references? I wish there was one page with a flat list, no clicking through nested rules to find out what each one pulls in.

Maybe that list already exists somewhere and it went completely over my head? If not, has anyone found a reliable way to build one? 

Here's what I've looked at:
1. [Mandatory Rules for Class A](https://www.fedramp.gov/2026/providers/20x/rules/fedramp-certification/#mandatory-fedramp-rules-for-class-a). It's a great starting point, but the rules are nested.
2. The JSON. Some subset that hold mandatory Class A rules are tagged Class B, C, and D only. So I am not sure if its required for Class A.
3. [What must be in a Class A Certification Package?](https://help.fedramp.gov/hc/en-us/articles/55366564534043-What-must-be-in-a-Class-A-Certification-Package). This is good overview but it only names of handful of rule IDs.
4. [Class A Self-Check](https://help.fedramp.gov/hc/en-us/articles/56860150862491-20x-Class-A-Self-Check). Helpful, but light, and I couldn't tell if it was meant to be complete.

## pete-gov (FedRAMP) — [2026-11-05T15:20:02Z](https://github.com/FedRAMP/community/discussions/190#discussioncomment-19421046)

> I wish there was one page with a flat list, no clicking through nested rules to find out what each one pulls in.

The Ruleset Reference page has all of the related rules (the ones referenced by FRC-CLA-MFR etc.) all in one page under [Related Rules](https://www.fedramp.gov/2026/reference/20x/a/related/), with a title edit indicating if the rule is Mandatory, Recommended, or Optional. I think that's 90% of what you're looking for?

It still requires you to click through to the Marketplace Listing, FedRAMP Certification, and Certification Package Overview rulesets so it's not ALL on one page, but the Related Rules was designed to address the "I want to read through the text of the extra rules in one go" itch.

I didn't put them ALL on one page because that would be huge, but it's a relatively simple task to do so. I think the layout would need to work differently. Let me know if the Related Rules bit in the reference and the other options near it meet your needs or not!

> The JSON. Some subset that hold mandatory Class A rules are tagged Class B, C, and D only. So I am not sure if its required for Class A.

Class A is a bit weird because it has both subsets that apply specifically to it and specific rules that list other rules - unlike Class B/C/D which all just are based on subset applicability. There's a bit of discussion about this in [this discussion in the rules issues](https://github.com/FedRAMP/rules/issues/43).

In short, a full list of Class A rules can be easily generated programmatically by:

1. Referencing the subsets that apply to Class A
2. Within those subsets, referencing the rules that contain lists of related rules (FRC-CLA-MFR, FRC-CLA-RFR, and FRC-CLA-OFR)

Creating a checklist in the preferred format of your choice is thus a trivial programmatic task using the rules JSON data. Any LLM/agent system that uses context and has a sufficient window to process the json can do this for you with ease, or write you a script/program to generate the list. Here's an example prompt you can use in a context that has the rules JSON loaded:

"List all rules related to Class A and their force, both because they are in a subset that applies to Class A or because they are mentioned in one of the Class A rules that lists related rules."
