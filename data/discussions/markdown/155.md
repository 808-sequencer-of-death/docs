[Class A Certification](https://help.fedramp.gov/hc/en-us/requests/new?ticket_form_id=51137131584283) is open for submission  ❤️ 🚀

Remember, you must first be listed on the FedRAMP Marketplace in [Initial Implementation status](https://www.fedramp.gov/2026/providers/implement/marketplace/#fedramp-rules-for-marketplace-listing) before you can submit for Certification.

When you received your Initial Implementation Marketplace listing, you will have been provided your FedRAMP ID. It is important that you have updated the `fedRampPackageId` in your Certification Package Overview (CPO) JSON file with this value.

Also worth noting for a Class A is that assessor info should ONLY be populated in your CPO JSON file IF you had an optional Independent Assessor perform an Independent Verification and Validation of your 20x materials. This is not for information related to your SOC2 auditor or GovRAMP or FedRAMP Rev5 3PAO, even if they are also officially FedRAMP recognized.
