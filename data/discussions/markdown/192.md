# A few typos in 2026.11.02.01 (SCN-FRP-CAP, FRD-IIR, SCN-CSO-EVA)
Source: https://github.com/FedRAMP/community/discussions/192

## Original post — kevinraymond, 2026-11-06T17:42:39Z

I've been processing `fedramp-consolidated-rules.json` with a small script and it turned up a few typos. Minor but dropping here anyway. All of these are in 2026.11.02.01.

**SCN-FRP-CAP**

- field `note` currently reads "... will vary and be documented in the _Correcive_ Action Plan."
- it should read: "... will vary and be documented in the _Corrective_ Action Plan."

**FRD-IIR**

- field `definition` currently reads: "... following _FedRAMP FedRAMP_ Incident Evaluation and Communication rules."
- it should read: "... following _FedRAMP_ Incident Evaluation and Communication rules."

**SCN-CSO-EVA**

- field `following_information`, second item, currently reads: "If it is, is it _an_ FedRAMP Certification class change?"
- it should read: "If it is, is it _a_ FedRAMP Certification class change?"

For completeness, two more in the update history if those matter:

- the 2026-07-01 comment on VDR-TFR-PVR shows "relevent"
- the CMU-CSO-UVM comment has a double space in "updates to  validated".

I didn't see any other issues - thanks!
