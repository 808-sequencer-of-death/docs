## In short

Key Security Indicators (KSIs) are the security capabilities a FedRAMP 20x cloud service offering demonstrates. There are 46 indicators in 10 themes, from identity and access management to recovery planning. Each one describes an outcome, such as "Logs are persistently reviewed and audited," rather than a specific control to implement.

KSIs are written as capability statements, not as MUST or SHOULD rules. What you must do with them comes from other rulesets: you document how you meet each KSI in your Security Decision Record, automate their verification and validation, and include them in your annual independent assessment. Class A uses 7 KSIs. Class B and C use all 46, and 5 of them are marked optional for Class B.

## Who it applies to

KSIs apply to **FedRAMP 20x** certifications only. Rev5 certifications use Rev5 controls instead.

| Class | Which KSIs | Source |
| --- | --- | --- |
| Class A | 7 KSIs: `KSI-CED-RAT`, `KSI-CMT-LMC`, `KSI-CNA-RNT`, `KSI-IAM-AAM`, `KSI-IAM-APM`, `KSI-INR-RIR`, `KSI-SVC-SIN` | [`FRC-CLA-MFR`](https://www.fedramp.gov/2026/reference/fedramp-certification/#mandatory-fedramp-rules-for-class-a) and the 20x Class A ruleset |
| Class B | All 46. Five are marked **Optional** for Class B (see [Differences by class](#differences-by-class)). | 20x Class B ruleset |
| Class C | All 46 | 20x Class C ruleset |
| Class D | The KSI reference doesn't publish Class D variants. | |

`FRC-CLA-MFR` says providers MUST address the listed KSIs to receive a Class A certification, even if they intend to pursue a Rev5 Program Certification path in the future.

## Key dates

The Key Security Indicators reference page doesn't publish its own effective dates. KSIs take effect through the rulesets that require them. Check the dates on those pages:

- [Security decision record](/rules/security-decision-record) (`SDR-CSX-KSI`, `SDR-CSX-KMT`)
- [FedRAMP certification](/rules/fedramp-certification) (`FRC-CLA-MFR`, `FRC-CSX-VVK`)
- [Independent verification and validation](/rules/independent-verification-and-validation) (`IVV-CSX-AIA`)

## How the other rules use KSIs

| Rule | Force | What it means for you |
| --- | --- | --- |
| [`SDR-CSX-KSI`](https://www.fedramp.gov/2026/reference/security-decision-record/#key-security-indicators) | MUST | For each applicable KSI, include short high-level summaries in your Security Decision Record: the measures that demonstrate it (or why you have none and the resulting risk), the cycle for persistent measures, verification, verification of your automation, and validation. |
| [`SDR-CSX-KMT`](https://www.fedramp.gov/2026/reference/security-decision-record/#key-security-indicator-metrics) | Class A MAY, Class B SHOULD, Class C MUST, Class D MUST | Include historical KSI metrics in your Security Decision Record. Class B: 30-day and up-to-a-year summaries. Class C adds all daily metric data for up to a year. Class D must significantly exceed lower classes, with specifics to be set during the 20x Phase 4 Pilot. |
| [`FRC-CSX-VVK`](https://www.fedramp.gov/2026/reference/fedramp-certification/#automated-verification-and-validation-of-key-security-indicators) | Class A MAY, Class B SHOULD, Class C MUST, Class D MUST | Implement automated methods to persistently verify and validate your KSIs. Class B: at least 1 automated method per KSI. Class C: at least 2. Class D: at least 4. |
| [`IVV-CSX-AIA`](https://www.fedramp.gov/2026/reference/independent-verification-and-validation/#annual-independent-assessments-for-20x) | MUST | Class B, C and D: include all KSIs in a FedRAMP independent assessment at least once a year. Class A: meet the expectations of your underlying alternative security framework. |

## What you need to do

Each table lists every indicator in the theme. KSIs carry no MUST or SHOULD force, so the tables show what each indicator asks you to demonstrate. "Class A" marks the 7 indicators that apply to Class A. "Optional for Class B" marks indicators published with an **Optional** label for Class B.

Key terms: [persistently](https://www.fedramp.gov/2026/definitions/#persistently), [information resource](https://www.fedramp.gov/2026/definitions/#information-resource), [machine-based information resources](https://www.fedramp.gov/2026/definitions/#machine-based-information-resources) and [federal customer data](https://www.fedramp.gov/2026/definitions/#federal-customer-data).

### Cybersecurity education (CED)

| Indicator | What it means for you |
| --- | --- |
| [`KSI-CED-RAT`](https://www.fedramp.gov/2026/reference/key-security-indicators/#reviewing-all-training) Reviewing All Training | Persistently review how effective your security training is. That covers at least general training for all employees, role-specific training for high-risk roles, secure software delivery training for engineers, and training for incident response and disaster recovery staff. Class A. |

## Differences by class

Five indicators publish separate Class B and Class C statements. The wording is the same, but the Class B statement is labeled **Optional**:

| Indicator | Class B | Class C |
| --- | --- | --- |
| `KSI-CNA-EIS` Enforcing Intended State | Optional | Same statement, no Optional label |
| `KSI-MLA-ALA` Authorizing Log Access | Optional | Same statement, no Optional label |
| `KSI-SVC-PRR` Preventing Residual Risk | Optional | Same statement, no Optional label |
| `KSI-SVC-RUD` Removing Unwanted Data | Optional | Same statement, no Optional label |
| `KSI-SVC-VCM` Validating Communications | Optional | Same statement, no Optional label |

All other indicators have a single statement that applies to every class that uses them. Class A uses only the 7 indicators listed under [Who it applies to](#who-it-applies-to).

## What FedRAMP staff have said

<Note>
  **You decide what counts as a distinct automated method.** On `2026-09-18`, asked how FedRAMP judges whether two automated validations are distinct methods under `FRC-CSX-VVK`, `pete-gov` said it is up to the provider. Poor choices make customers less likely to find your assurance adequate. He said FedRAMP will include its own report on how assuring and diverse it finds your methods during certification. [Discussion #176 comment](https://github.com/FedRAMP/community/discussions/176#discussioncomment-18501048)
</Note>

<Note>
  **No FedRAMP-defined minimum configuration baseline.** On `2026-09-02`, in a thread about meeting secure configuration expectations for 20x (the question referred to "ACM" and to CIS benchmarks and DISA STIGs), `pete-gov` confirmed there is no FedRAMP-defined minimum tier, as long as your chosen configuration is risk-based, applied and evidenced. He noted that this covers only obtaining and keeping a FedRAMP Certification, and some agency customers might write such requirements into their contracts. [Discussion #147 comment](https://github.com/FedRAMP/community/discussions/147#discussioncomment-18256476)
</Note>
